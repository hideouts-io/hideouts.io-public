What this preview can tell you

A transparent comparison,
with the limits attached.

Retained: actual public-area coordinates, full LTE/NR identities, network codes, TAC, PCI lists, channels, and useful technical evidence fields. Carrier names are labels for network codes, not a claim about who owns a physical structure.

Excluded: personal cache histories, private geofences, identifying Wi-Fi addresses, account or device identifiers, credentials, personal contacts, and private local paths. This is a separate review dataset; the original private Atlas remains unchanged.

Not established: a record’s presence on a Mac does not establish a visit, a connection, live tracking, or an individual’s movements. A returned estimate, a permit address, and a surveyed antenna location are different claims. Observation time is shown only when the underlying source supports it.

This preview makes no requests to map providers, carrier services, analytics services, or location/device APIs. Source links open only when you choose them.
